sheet-api upload a CSV, get a read-only REST JSON API

Upload a CSV. Get a JSON API for it.

Pick a CSV file (first row = column names). Column types (text/number/boolean) are detected automatically. You'll get an API key and a URL you can GET with pagination, sorting and exact-match filtering — no account required for the free tier.

Create a project

Endpoints

  • GET /data/:id/columns — column names and inferred types
  • GET /data/:id/rows?limit=&offset=&sort=&order=&<col>=value — paginated, sortable, filterable list
  • GET /data/:id/rows/:rowId — a single row

Limits (free plan)

  • 3 live projects, 1MB CSV, 5,000 rows, 50 columns
  • 120 requests/min per project
  • projects expire after 30 days
